# Security policy

[Report a vulnerability privately on GitHub](https://github.com/Go-Gen-Ecosystem/go-migrate/security/advisories/new).
Use the private form for suspected vulnerabilities and
[GitHub Issues](https://github.com/Go-Gen-Ecosystem/go-migrate/issues) for ordinary bugs.

Include the following details when available.

- Affected go-migrate version and how you installed or invoked it.
- Database engine and version, if relevant.
- Minimal steps to reproduce the issue on a disposable database.
- Expected behavior, observed behavior, and security impact.

Redact credentials, connection strings, and production data from examples and
logs. If you can reproduce the issue on the
[latest stable release](https://github.com/Go-Gen-Ecosystem/go-migrate/releases/latest),
include that result along with any older versions you tested.
